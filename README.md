# 社团百宝箱 · 百团大战新生选社（游客端 + 负责人端）

社团文化节 / 百团大战用的新生选社工具：兴趣标签开屏 → 按模块匹配推荐社团 → 可交互场馆平面图（缩放拖动 / 搜索定位 / 摊位状态），并带**负责人模式**（社团负责人手机上实时维护自己的摊位信息）。

## 功能

### 游客端（新生用）
- **两步开屏**：四大模块（公益 / 人文 / 科技 / 体育）选一 → 模块内勾选兴趣标签
- **为你推荐**：标签匹配算法排序，显示匹配度、前三名徽标、摊位号
- **场馆平面图**：舞台 / 观众区 / 门头 + 摊位队列，支持双指缩放、拖动、按钮缩放
- **搜索定位**：搜社团名 / 标签 / 摊位号，地图自动放大聚焦并高亮闪烁
- **摊位状态**：摆摊中 / 已收摊（收摊格子灰化划线），负责人改动 ≤20 秒自动生效
- **QQ 群一键复制**、照片懒加载、离线兜底（接口不可用时自动回退内置数据）

### 负责人端（开屏页底部「负责人入口」或访问 `#leader`）
- **邀请码登录**：管理员私发邀请码，一人一码，输一次绑定微信/浏览器，免密码
- **摊位控制台**：一键切换 出摊中 / 已收摊，游客端地图实时变色
- **照片管理**：手机相册选图，前端自动压缩（长边 1280 / JPEG），最多 6 张，可删除
- **编辑资料**：口号 / 图标 / QQ 群 / 介绍 / 活动；社团名称对负责人只读
- **权限隔离**：数据库层校验 `只能改自己的社团`，摊位号仅管理员可分配
- **管理员面板**：用超管口令登录，可改所有社团、分配摊位、生成/重置邀请码

## 架构与运行

```
club-fair/
├── server.js          # 纯 Node 后端（零依赖）：静态托管 + API + 上传 + 会话
├── public/            # 前端（原生 HTML/CSS/JS，零构建）
│   ├── index.html
│   ├── css/style.css
│   └── js/{data.js, app.js}
├── data/seed.json     # 服务端初始数据（含超管口令，勿提交/勿外传）
├── data/db.json       # 运行时数据库（首次启动自动从 seed 生成，含邀请码）
├── scripts/gen-seed.js# 改完 data.js 后重新生成 seed：node scripts/gen-seed.js
└── uploads/           # 负责人上传的照片
```

启动：`node server.js`（监听 `PORT` 环境变量，默认 3000）。

- 邀请码在服务端首次启动时自动生成，管理员登录后在面板里查看/重置
- 登录接口带限流（10 分钟 8 次失败锁定），会话 30 天有效
- 数据持久化在部署环境内；如部署沙箱重建，数据回退到 seed（重新生成邀请码）

## 数据维护（活动筹备同学看这里）

- **改动初始数据**：编辑 `public/js/data.js`（文件头部有完整指南）→ 运行 `node scripts/gen-seed.js`
- **活动当天的实时改动**：全部走负责人端界面，无需改代码
- 摊位平面图布局：`public/js/data.js` 的 `MAP_LAYOUT`
